Numel UI Exploration

Three directions to make Numel feel less like an engineering console.

These concepts are lightweight visual probes. They keep the same product model underneath: spaces, one current workflow per space, tags on the canvas, assistant entry, and local-to-prod platform continuity. The goal is to choose a better mood, hierarchy, and onboarding shape before redesigning the live app.

Recommended

Project Workbench

Calmer, clearer, and more obviously project-shaped. This treats a space like a workbench, keeps the canvas central, and makes first actions feel approachable instead of technical.

  • Best for broadening beyond expert users without losing the builder identity.
  • Strong visual hierarchy between current project, starter actions, canvas, and runs.
  • Good base for the product roadmap already started.

Assistant-led

Assistant Studio

This version makes the assistant the front door. It is strongest if the product promise becomes “describe what you want, then refine the workflow visually.”

  • Great first-run flow for less technical users.
  • Stronger planner and `/gen` framing.
  • Risk: canvas can start to feel secondary.
Open concept
Multimodal-first

Creative Agent Studio

A more expressive direction for media capture, previews, and live multimodal workflows. It makes Numel feel bolder and more differentiated, especially around browser-native inputs.

  • Best for demos, creator workflows, and live media identity.
  • Most distinctive visual language.
  • Risk: can oversignal “creative tool” over general workflow product.

Suggested next move

Choose one direction quickly, then apply it to a thin vertical slice: auth and first-run onboarding, the space/workflow left rail, the starter state, and the assistant entry point. The strongest default path is Project Workbench with selective Assistant Studio elements.
