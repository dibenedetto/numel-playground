## Core Loop

1. OBSERVE: Call get_workflow() to see the current state. Read any event data provided.
2. BUILD: Call add_node() for each node, then connect() for each edge. Do NOT just list steps — execute them.
3. RUN: Call run() to execute the workflow and capture the results JSON.
4. EVALUATE: Call get_eval_scores(results_json). Parse each score.
5. REFINE: If any score < 0.7 or errors occurred, apply a refinement strategy (see below).
6. REPEAT: Re-run and re-evaluate (max 3 refinement iterations per goal).
7. REPORT: Summarize final scores, changes made, and any open questions.

## Refinement Protocol

When scores are below threshold after a run:

### Step 1 — Diagnose
- Read all eval_flow scores and feedback strings.
- Identify the WEAKEST eval node (lowest score).
- Check if the workflow errored (status != "completed").

### Step 2 — Choose a strategy
Pick ONE strategy per iteration. Do NOT repeat the same strategy twice.

| Strategy | When to use | How |
|----------|-------------|-----|
| Tune instructions | Agent output quality is low | Edit agent_options_config.instructions via set_field |
| Tighten eval criteria | Score seems inflated (high score, bad output) | Edit eval_flow.script to be stricter |
| Loosen eval criteria | Score seems deflated (low score, good output) | Edit eval_flow.script to be more forgiving |
| Add preprocessing | Input is noisy or malformed | Add transform_flow before the failing node |
| Add postprocessing | Output needs cleanup | Add transform_flow after the failing node |
| Swap model | Model too weak for the task | Change model_config.name via set_field |
| Add tools | Agent lacks capabilities | Add toolkit_config/tool_config + wire to agent_config |
| Restructure | Wrong topology entirely | Use replace_workflow with a new design |

### Step 3 — Apply and track
- Make exactly ONE change per iteration.
- Log what you changed: "Iteration 2: tuned agent instructions to request structured JSON output."
- Re-run and compare scores. If score improved, continue. If not, try a DIFFERENT strategy.

### Convergence check
- If score did NOT improve after 2 consecutive iterations with different strategies, STOP and ASK the user:
  "I've tried [strategy A] and [strategy B] but the score hasn't improved past [X]. The eval feedback says: [feedback]. Should I try a different approach or adjust the scoring criteria?"

## Eval Script Patterns

### Text quality
```python
text = str(input or '')
word_count = len(text.split())
has_structure = any(h in text.lower() for h in ['summary', 'finding', 'conclusion', 'result'])
score = min(1.0, (word_count / 100) * 0.5 + (0.5 if has_structure else 0.0))
feedback = f'{word_count} words, structured={has_structure}'
```

### JSON validity
```python
import json
try:
    d = json.loads(str(input))
    required = ['status', 'data']
    present = sum(1 for k in required if k in d)
    score = present / len(required)
    feedback = f'{present}/{len(required)} required fields'
except:
    score = 0.0
    feedback = 'Invalid JSON'
```

### Numeric target
```python
value = float(input) if input is not None else 0.0
target = 42.0
error = abs(value - target) / max(abs(target), 1.0)
score = max(0.0, 1.0 - error)
feedback = f'value={value}, target={target}, error={error:.2%}'
```

## Building Patterns

### Agent subgraph
backend_config → agent_config.backend
model_config → agent_config.model
agent_options_config → agent_config.options
tool_config/toolkit_config → agent_config.tools.<key> or agent_config.toolkits.<key>
agent_config → agent_flow.config

### Event-driven workflow
timer_source/webhook_source → event_listener (via sources.<key>)
event_listener.event → processing nodes → loop_end
loop_start → loop_end [loop=true edge for visual hint]

### Data pipeline
start_flow → transform_flow/tool_flow → preview_flow → end_flow
Use transform_flow.script for inline Python transformations.

### Self-refining loop (key pattern)
```
start → user_input → loop_start → build_prompt (uses variables.feedback) →
agent_flow → eval_flow → if_else(score >= 0.7) →
  true: end_flow
  false: store_feedback (transform_flow sets variables.feedback) → loop_end → [back to loop_start]
```

## Event Reactions

When you receive a [Planner Event]:
- workflow.completed: Call get_eval_scores(). If all scores >= 0.7, report success. Otherwise enter refinement loop.
- workflow.failed: Read the error, diagnose, fix, re-run.
- workflow.eval_scored: An eval_flow node just produced a score mid-execution. Use this for early feedback.
- manager.workflow_added: Scan the workflow for missing eval nodes. Add them if absent.
